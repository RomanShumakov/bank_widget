# Виджет банковских операций
Виджет, который показывает несколько последних
успешных банковских операций клиента.

## Инструкции по установке виджета
#### *Команды необходимо вводить в terminal (командную строку компьютера)*
1. Склонируйте код из удаленного репозитория командой:  
```
git clone git@github.com:RomanShumakov/bank_widget.git
```
2. Установите интерпретатор [python](https://www.python.org/)
3. Установите зависссимости командой:    
```
poetry install
```
## Инструкции по использованию виджета
Программа состоит из нескольких модулей,
каждый из которых предоставляет определенный функционал.
Для выполнения программы необходио запустить модуль "main".

### Модуль widget
Предоставляет функции маскировки дебетовых карт и номеров счета,
а так же изменения формата даты.
Обращается к модулю **masks** для выполнения конкретной операции.

Для маскировки необходимо вызвать функцию mask_account_card, и передать ей
в качестве аргумента тип (название карты или счет, опционально), а так же номер
(16 цифр для карты, 20 цифр для счета).

#### Пример работы функции mask_account_card:
Входные данные: `Visa Platinum 7000792289606361`    
Выходные данные: `Visa Platinum 7000 79** **** 6361`

#### Другой пример работы функции mask_account_card:
Входные данные: `Счет 73654108430135874305`     
Выходные данные: `Счет **4305`

Для изменения формата даты необходимо вызвать функцию get_date, и передать ей
в качестве аргумента дату формата: *YYYY-MM-DD'любое число символов'*.

#### Пример работы функции get_date:
Входные данные: `2024-03-11T02:26:18.671407`    
Выходные данные: `11.03.2024`

### Модуль processing

Статус фильтрации по умолчанию: "EXECUTED" (выполненно).

### Модуль decorators
Модуль содержит декораторы, в которые при желании можно оборачивать функции.
#### Декоратор log
Декоратор служит для вывода логов с возникающими ошибками работы функции (при их наличии) 
или с результатами успешной работы функции (при отсутствии ошибок). Декоратор имеет необязательный
параметр filename, указывающий, в какой файл записывается информация о логировании.
По умолчанию этот параметр равен None, что означает вывод в консоль. Если логирование требуется записать
в конкретный файл - его название необходимо указать в качестве параметра (например, "tempfile.txt").
Если указать несуществующий файл - программа автоматически его создаст.

**Пример использования декоратора log (вывод резуьтатов в консоль)**

Входные данные:
```
@log()
def my_function():
    return "result"

my_function()
```
Выходные данные:
```
Функция my_function успешно завершила выполнение за 5,05823 сек.: result
```
**Пример использования декоратора log (вывод ошибки в файл "tempfile.txt")**

Входные данные:
```
@log("tempfile.txt")
def error_function():
    raise ValueError("something went wrong...")

error_function()
```
Выходные данные:
```
error_function error: ValueError. Inputs: (), {}"
Время выполнения: 5,05823
```

### Модуль re_search.py
В данном модуле реализованы функции process_bank_search и process_bank_operations.
#### Функция process_bank_search
Функция фильтрации списка транзакций по вводимой пользователем операции. Для фильтрации необходимо передать через запятую в качестве аргументов список странзакций
и искомую операцию.
#### Функция process_bank_operations
Функция возврата колличества операций по каждой указанной категории на основе списка банковских операций. Для получения колличества каждой категории
необходимо передать через запятую  в качестве аргументов список странзакций и список категорий, по которым требуется получить колличество.
